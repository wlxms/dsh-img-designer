# 模板字段说明

每个模板文件都用同一套字段，方便机器拼、人读、以后加上下文。

```markdown
---
id: shot-xxx              # 唯一 id，文件同名
kind: shot | light | meta # 主干 / 修饰 / 元
name: 中文名
use_when: 什么时候用它（一句话，可判定）
avoid_when: 什么时候别用它（一句话）
slots: [a, b, c]          # 必须填的槽位，填不出回 brief
defaults: { aspect: "4:3", lens: "85mm", light: "light-softbox" }
---
```

正文固定五节，顺序不要变：

| 节 | 内容 | 上限 |
|---|---|---|
| `## 骨架` | 英文提示词骨架，`{{slot}}` 占位 | 主干 40–120 词；修饰 25–60 词 |
| `## 负向` | 本模板特有的负向（全局的在 `_negative.md`） | 5 行 |
| `## 验收锚点` | 这个类型最常翻车的 3 条，可逐条判 PASS/FAIL | 3 条 |
| `## 变体` | 可叠加的修饰或参数替换 | 5 行 |
| `## 踩坑记录` | 用出来的教训，随使用追加 | 不限，半年合并一次 |

## 写作规矩

1. **骨架只写可变的部分**。固定措辞（不要塑料感、不要 HDR）统一放 `_negative.md`，不在每个模板里重复。
2. **一个模板只解决一种构图**。想覆盖两种，拆成两个。
3. **修饰层要能独立成立**。它会被拼在主干后面，读的人（模型）看不到上下文，所以 25 词起，说清"光从哪来、影子什么样"。
4. **验收锚点必须可判定**。"要有美感"不合格；"地面接触影存在且方向与主光一致"合格。
4. **槽位名保持稳定**。`{{object}}` 不要一会儿叫 `{{product}}`，不然没法拼。
5. 新模板先从 `_schema` 抄骨架，别自由发挥。
