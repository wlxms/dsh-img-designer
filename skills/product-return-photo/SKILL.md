# 产品返图：让商品照看起来"真的被用过"

**目标**：让看图的人相信「这个人已经买了、放在自己家里用着」，不是「这个商品长什么样」。
**适用**：桌面小物、自发光小家电、香薰、化妆镜等"放上去就不会再动"的东西。
**不适用**：需要手持、穿戴、正在动的商品（那是使用示范，不是返图）。

## 总原则

1. **主体不做主角**：不居中、不正对、允许被遮挡 20–30%、允许压边。商品看不全是**结果**，不是让步。
2. **曝光只对一处正确**：夜里就是那盏灯，白天就是窗边那块。AI 感来自"所有东西都恰到好处"。
3. **每个物件都能被正常使用且符合常识**：空间要能走、抽屉要能拉、窗要能开、插座要能插、灯要照到人。

---

## 第 0 关 · 硬门槛（一条不过，不进入打分）

### 空间可用性
1. 床头柜/边几紧贴家具，与台面高差 ≤5cm
2. 抽屉或柜门前方净空 ≥ 深度 +10cm
3. 窗前净空 ≥ 60cm（能走到窗边开关窗、拉帘）
4. 窗帘下摆不被任何家具压住
5. 插座在台面上方 60–70cm，或台面旁不被遮挡
6. 主要家具至少一侧留 ≥50cm 通行；主走道 ≥60cm
7. 门/衣柜开启扇不压家具

### 产品就位
8. **朝向以使用者为参照**：朝床、朝枕头、朝房间——不要用"斜 X 度"这种以镜头为参照的描述
9. 光落在人身上，不落在墙上（刻意做氛围除外）
10. 底座完全在台面内，离台沿 ≥5cm，不压抽屉前沿
11. 电源线从底座后方出、朝插座一侧走，不横穿台面
12. 线长 ≥ 灯具到插座直线距离 ×1.3
13. 使用者躺下/坐下时看得见、起身不会碰到

### 写法约束
14. 家具关系用 **相机站位 + 平面图** 锁定，不用物件清单。
    示例：相机在床的中段旁边、离床头约一米，朝床头方向看；床头软包靠右墙；床头柜夹在床头与右墙之间，抽屉朝画面左前；窗在左墙，与床头墙成直角，窗下留 60cm 过道；床尾在画面外。
15. 产品朝向用 **人的位置** 描述，不用相对镜头的角度。

## 第 1 关 · 三轴配比

### D｜陈旧度（单件 0–1）
0 出厂崭新 → 0.3 用过但整洁 → 0.6 明显在用、开始旧 → 1.0 老/脏/起球/积灰

### A｜随意度（单件 0–1，含重复衰减）
类别：倒、开、缠线、散叠、压遮、撕、用剩、**不搭**（与周围年代/材质/风格冲突的廉价物，s=0.9）。
同一类别第 n 次出现：

    n = 1  → +s
    n = 2  → +0.5s
    n = 3  → +0.25s
    n ≥ 4  → −0.25s × (n−3)        # 第 4 次起倒扣：重复的"随意"读起来就是安排随意

### R｜重复度
    R = 1 − K/N      K = 类别数，N = 实例数
R→1 表示同一个动作反复出现。

### 加权与阈值（**预注册，不许事后调整**）
按元素像素占比 w 加权：

    D̄   = Σ w·D
    σ_D = √( Σ w·(D−D̄)² )
    A   = Σ w·s_eff

| 指标 | 阈值 |
|---|---|
| D̄ | 0.25 – 0.50 |
| σ_D | ≥ 0.20 |
| A | 0.22 – 0.40 |
| R | ≤ 0.50 |

### 三层结构
| 层 | 面积 | 作用 | 硬要求 |
|---|---|---|---|
| 面（墙/床/台面/地面） | ≥15% | 定基调 | 至少一个面 D ≥ 0.40 |
| 件 | 3–15% | 承担 A 的主要来源 | ≥3 个不同类别，每类 1 次 |
| 碎 | <3% | 只补细节 | 不作为证据 |

主体放在「件」层：面积 5–15%、D ≤ 0.1、A = 0、清晰度最高。

### 六条结构性判据（不依赖阈值）
1. 遮住主体，这仍是"某人的房间"
2. 至少有一个"完全没有含义"的物件
3. 至少一处曝光是错的（过曝/死黑/闪光硬阴影/焦点跑偏）
4. 画框切掉了东西
5. 至少一对相邻物件 |ΔD| ≥ 0.50
6. 至少一个物件 |D−a| ≥ 0.40（新旧与随意不同步）

## 第 2 关 · 提示词八段骨架

    1 谁、在什么时刻、用什么姿势拍
    2 相机站位 + 平面图
    3 空间可用性（净空、插座、窗帘、抽屉）
    4 材质与陈旧度（D 分布）
    5 场景动作（A 预算，每类只写一次）
    6 产品摆放与朝向（按人的位置写）
    7 光与曝光（只对一处正确）+ 摄影缺陷（焦段、噪点、歪 2–3°）
    8 裁切残缺 + 负向 5–8 条

### 负向清单
拖鞋、单独一杯水、摊开的书、搁在书上的眼镜；正对镜头、居中、对称；"斜 X 度"这类相对镜头的角度；空墙+悬浮木架；墙面装饰三件套（照片墙+便签+挂钟）；台面无瑕疵；全图统一暖调；收藏品等距正立；**为了暗示生活而放进去的任何东西**。

### 槽位（每次只换一个）
空间类型（出租屋/精装小公寓/合租单间/独居小户型）、受众（女大学生/白领女性/情侣/男生）、拍摄时刻（刚拆封/用完还没收/躺床上/开闪光/白天）、品类。

## 第 3 关 · 后期（确定性，不靠模型）

1. 旋转 1.5–3° 并重裁：切掉柜角、切掉墙架、产品压边
2. 色散：R/B 通道径向缩放 0.12–0.18%
3. 颗粒：不均匀、暗部更重（σ ≈ 0.010–0.017）
4. 暗角：径向衰减 0.20–0.40
5. 四角软化：叠 1.5–2.5px 高斯模糊
6. 压高光：>0.90 柔化到 1.0，去掉假 HDR
7. 冷阴影 / 暖高光分调

**必检**：刻字、角色脸部、结构、有无新增黑边或撕裂。

---

## 第 4 关 · 验收

六问（任一不过就不交）：
1. 遮住产品，这还是一张"某人的房间"吗？
2. 有没有至少一样毫无含义的东西？
3. 有没有一处曝光是错的？
4. 画框有没有切掉东西？
5. 相邻物件有没有互相遮挡、挤压？
6. 有没有哪样东西是"为了暗示生活"放进去的？有就删。

数值验收：按第 1 关阈值逐项打钩，阈值必须在看图之前写下。

## 失败模式对照

| 现象 | 根因 | 修法 |
|---|---|---|
| 从整洁改成混乱反而更假 | 全图 D 整体平移，跨度不足 | 拉跨度，不抬水位 |
| 加道具永远不管用 | 道具面积权重太小 | 改「面」层 |
| 线条笔直、构图对称 | 没做后期旋转/重裁 | 第 3 关 |
| "乱"被理解成更乱更脏 | 单一类别重复 | R ≤ 0.5，每类 1 次 |
| 家具有摆拍感/浮空 | 只写了物件清单 | 用相机站位+平面图 |
| 家具用不了（床堵窗、柜在床尾） | 没做第 0 关 | 先过功能门槛 |
| 商品被摆成正对镜头 | 朝向以镜头为参照 | 改成以使用者为参照 |
| 光很"好看"但假 | 暗调本身是审美选择 | 让曝光失败一次 |

## 已知边界
- 中文字还原不稳定（实测 8 张里 1 张出错），刻字重要时单独验证
- 编辑会引入破损（曾把画面一角撕出纯黑），必须逐张查边角
- "旧"和"乱"会被放大（灰尘变土块），所有痕迹都要给上限
- 无外部参考时判断依赖经验；拿不到真实房间照片时，用第 0 关+三轴替代
